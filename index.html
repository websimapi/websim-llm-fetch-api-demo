In-Site LLM Fetch API Demo

This page demonstrates how to use the in-site Language Model (LLM) capabilities provided by websim to make AI-powered requests directly from your web application.

How It Works

The websim object provides access to AI capabilities right in your browser. Here's how you can leverage these features:

Basic AI Chat

Send messages to the AI and get responses:

let conversationHistory = [];

// In your message send handler:
const newMessage = {
  role: "user",
  content: "What is two plus two?",
};

// Add to conversation history
conversationHistory.push(newMessage);

// Only keep the last 10 messages 
conversationHistory = conversationHistory.slice(-10);

// Make the AI request
const completion = await websim.chat.completions.create({
  messages: [
    {
      role: "system",
      content: "You are a friendly assistant who speaks in rhyming verse.",
    }, // System message is optional
    ...conversationHistory,
  ],
});

const response = completion.content;

// Add the AI response to the conversation history
conversationHistory.push(completion);

JSON Output

Request structured data from the AI:

const completion = await websim.chat.completions.create({
  messages: [
    {
      role: "system",
      content: `Combine the following concepts into a single, coherent idea.
Respond directly with JSON, following this JSON schema, and no other text.
{
  concept: string;
  emoji: string;
}`,
    },
    {
      role: "user",
      content: "eggs + fire",
    }
  ],
  json: true,
});

const result = JSON.parse(completion.content);
let concept = result.concept;
let emoji = result.emoji;

AI Image Generation

Generate images from text prompts:

// Generate with default square aspect ratio
const result = await websim.imageGen({
  prompt: "A crayon child's drawing of a turtle",
});

// Generate with specific aspect ratio
const result = await websim.imageGen({
  prompt: "A beautiful sunset over a calm ocean",
  aspect_ratio: "16:9",
});

// Generate with specific dimensions
const result = await websim.imageGen({
  prompt: "A beautiful sunset over a calm ocean",
  width: 1024,
  height: 768,
});

// Use a seed for variations
const result = await websim.imageGen({
  prompt: "A beautiful sunset over a calm ocean",
  seed: 4,
});

console.log(result.url);
